模型公式说明（与 roofline_probe.py / ep_probe.py 一致） 
C = coef·R·F·K / cube_TFLOPS          ← 全层 GEMM 时间（ms），R = M·topK
                                        整层 coef=22（fwd 6 + bwd 16）；仅反向 coef=16（重计算口径）
N = 4 × max(三条腿 流量÷带宽)          ← 每层 4 趟通信（fwd/bwd × dispatch/combine），单位 ms
四级命中概率（均衡路由 + 均匀 expert 放置）：
  本卡        1/EP                    → 走 HBM，不计网络
  节点内他卡  (R_node−1)/EP           → 走 HCCS fullmesh
  柜内他节点  （柜内卡数−R_node)/EP    → 走柜内互联
  其他机柜    1 − 柜内卡数/EP         → 走跨柜网络
  三条腿独立硬件、同时发货 → 每向时间 = max(三腿 流量÷带宽)
串行（小算子）T = C + N ；理想融合 T = max(C, N)
加速上限 = (C+N)/max(C,N) < 2.0 ；重叠率 = min(C,N)/max(C,N)
流量 = M·topK·K·2B（BF16），MB ÷ (GB/s) = ms

易混点：① 显存页的 R（接收容量，决定 [R,K]/[R,F] 等分配）≠ Roofline 页公式里的 R = M·T（总路由行数，算 FLOPs 用）；均衡路由下两者相等。 ② 账本公式直接使用面板字段名 EP/EPR——kernel 头文件里对应记号是 P/E。 ③ 计数表 [EP,S]：第 src 行前 EP·EPR 个有效，其余为对齐 padding。

字节公式来源：kernels/mega_moe_bf16/include/mega_moe_training_workspace.h、 mega_moe_workspace_info.h、mega_moe_base.h（PeermemInfo）、 csrc/ops/mega_moe_bf16_mgroup.cpp 与 test/megamoe_bf16_test/test_workspace_layout.py；锚点取自 docs 《MegaMoe_BF16_MXFP8_saved_state第一版》《前向持久Workspace第一版与反向适配》§3.3/§9.2。 估算口径：topk_ids 按 int32；x/y 与优化器状态由框架持有，不计入算子 workspace。

SHMEM 额度规则：额度建议 = Align2MiB(布局需要量)——local_mem_size 仅服务本算子， 固定 shape 按需给即可；须 2 MiB 对齐，且 shmem.init(size) 与算子构造传同一个值，不足即报错 need=需要量。 测试脚本（test_mega_moe.py local_mem_bytes）另有固定底座口径：Align2MiB(max(底座, 需要量))， 底座普通/MGroup 2 GiB、UDMA 3 GiB，用于一次 init 兜多种 case。
