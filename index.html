易混点：① 显存页的 R（接收容量，决定 [R,K]/[R,F] 等分配）≠ Roofline 页公式里的 R = M·T（总路由行数，算 FLOPs 用）；均衡路由下两者相等。② 公式的 P/E 是 kernel 头文件的 单字母约定，与面板的 EP/EPR 同义。③ 计数表 [P,S]：第 src 行前 P·E 个有效，其余为对齐 padding。

字节公式来源：kernels/mega_moe_bf16/include/mega_moe_training_workspace.h、 mega_moe_workspace_info.h、mega_moe_base.h（PeermemInfo）、 csrc/ops/mega_moe_bf16_mgroup.cpp 与 test/megamoe_bf16_test/test_workspace_layout.py；锚点取自 docs 《MegaMoe_BF16_MXFP8_saved_state第一版》《前向持久Workspace第一版与反向适配》§3.3/§9.2。 估算口径：topk_ids 按 int32；x/y 与优化器状态由框架持有，不计入算子 workspace。

SHMEM 额度规则：额度建议 = Align2MiB(布局需要量)——local_mem_size 仅服务本算子， 固定 shape 按需给即可；须 2 MiB 对齐，且 shmem.init(size) 与算子构造传同一个值，不足即报错 need=需要量。 测试脚本（test_mega_moe.py local_mem_bytes）另有固定底座口径：Align2MiB(max(底座, 需要量))， 底座普通/MGroup 2 GiB、UDMA 3 GiB，用于一次 init 兜多种 case。
